课前准备 · Structure

最简单的 C# 项目结构

用 dotnet new console 创建项目，得到的就是下面这个文件/文件夹骨架。

HelloWorld/ — 目录树
HelloWorld/                   项目根目录
├── HelloWorld.csproj        项目文件（SDK、依赖）
├── Program.cs               入口代码（顶层语句）
├── obj/                      编译中间产物（自动生成）
└── bin/                      编译输出（可执行 / DLL）
HelloWorld.csproj项目文件：声明 SDK、目标框架与依赖，是整个项目的"身份证"。
Program.cs入口代码：程序从这里开始执行（顶层语句或 Main 方法）。
obj/中间产物：编译过程的临时文件，自动生成，无需关心。
bin/编译输出：生成的 DLL / 可执行文件，dotnet run 即运行这里的内容。

02 / 变量

类型转换

在不同数据类型之间转换值。

Program.cs
// 隐式转换：安全，小范围 → 大范围

// 显式转换（强制类型转换）
double x = 9.99;
int y = (int)x;        // y = 9，小数被截断

// 字符串 ↔ 数字
int n = int.Parse("123");
string s = n.ToString();
要点小转大隐式完成；大转小需用 (类型) 强转，可能丢失精度。

04 / 条件语句

else if 多分支

依次判断多个条件，命中即停。

Program.cs
int score = 85;

if (score >= 90)
    Console.WriteLine("优秀");
else if (score >= 80)
    Console.WriteLine("良好");
else if (score >= 60)
    Console.WriteLine("及格");
else
    Console.WriteLine("不及格");
要点多分支依次判断，命中一个后其余不再执行；单条语句可省略花括号。
04 / 条件语句

嵌套 if

要点if 可以嵌套，注意花括号配对与缩进，保持代码清晰。
04 / 条件语句

三元运算符 ?:

Program.cs

要点条件 ? 值1 : 值2，条件为真返回"值1"，否则返回"值2"。
04 / 条件语句

switch 语句

对同一变量做多值匹配。

Program.cs
int day = 3;

{
    case 1:

        Console.WriteLine("星期二");

要点switch 按值匹配 case，default 处理未匹配情况，break 结束分支。
04 / 条件语句

switch 表达式

C# 8+ 更简洁的 switch 写法。

Program.cs
int day = 3;

string name = day switch
{
    1 => "星期一",
    2 => "星期二",
    3 => "星期三",
    _ => "其他"
};

Console.WriteLine(name);
要点switch 表达式用 => 直接返回结果，_ 是默认匹配，无需 break。

05 / 循环

for 循环

适合已知次数的计数循环。

{

05 / 循环

while 循环

先判断条件，成立才执行。

Program.cs
int i = 0;

while (i < 5)
{
    Console.WriteLine(i);
    i++;
}
要点先判断后执行，条件为 true 才进入循环体；别忘了在循环体内更新条件变量。
05 / 循环

do-while 循环

先执行一次，再判断条件。

Program.cs
int i = 0;

do
{
    Console.WriteLine(i);
    i++;
} while (i < 5);
要点先执行一次循环体再判断，保证至少执行一次。
05 / 循环

foreach 循环

遍历数组或集合中的每个元素。

Program.cs
int[] nums = { 10, 20, 30 };

foreach (int n in nums)
{
    Console.WriteLine(n);
}

要点foreach 自动取出集合中每个元素，简单安全，适合只读遍历。
05 / 循环

break 与 continue

控制循环的跳出与跳过。

Program.cs
for (int i = 0; i < 10; i++)
{
    if (i == 3) continue;  // 跳过本次
    if (i == 7) break;     // 终止循环
    Console.WriteLine(i);
}
// 输出：0 1 2 4 5 6

方法重载

同名方法，参数列表不同。

Console.WriteLine(Add(1, 2, 3));   // 三参数版本

递归调用

方法自己调用自己，解决可分解问题。

Program.cs

}

06 / 函数

ref 与 out 参数

让方法能修改外部变量或输出结果。

Program.cs
